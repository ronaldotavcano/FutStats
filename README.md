# FutStats

## Objetivo

O objetivo do FutStats é mapear os jogadores mais baratos e eficientes que um time pode contratar para ser campeão. Esse projeto foi inspirado no filme O Homem que Mudou o Jogo (Moneyball), a análise cruza o valor financeiro dos atletas com métricas de desempenho que impactam diretamente na geração de vitórias. A meta final é descobrir talentos subvalorizados que oferecem a melhor relação custo-eficiência, provando que é possível montar um elenco com potencial de título maximizando o retorno sobre o investimento.

## Amostra e População

A análise é baseada na temporada de 2025 do Campeonato Brasileiro, englobando os 20 times que disputaram a competição. Para compor a amostra de estudo e evitar distorções no cruzamento de dados, estabeleceu-se uma regra de corte: apenas atletas com pelo menos 900 minutos jogados foram incluídos. Isso garante que as métricas individuais avaliadas pelo modelo Moneyball tenham volume de jogo suficiente para comprovar o impacto real do jogador no time.
